# AZV Radar - Prospecção B2B Inteligente

Plataforma premium para prospecção, CRM e automação comercial.

## Setup no Lovable
1. Conecte este repositório ao Lovable.
2. O Lovable detectará automaticamente o Vite/React na raiz.
3. Configure a variável de ambiente VITE_API_URL no painel do Lovable para seu backend.
